# Workout Log

ระบบบันทึกการออกกำลังกาย (Workout Log)

## รายละเอียดโครงการ

เว็บแอปพลิเคชันสำหรับบันทึกและจัดการข้อมูลการออกกำลังกาย
ผู้ใช้สามารถเพิ่ม ดู แก้ไข และลบข้อมูลการออกกำลังกายได้
รวมถึงสามารถกรองข้อมูลตามประเภทการออกกำลังกายและแสดงข้อมูล
บนปฏิทินตามวันที่บันทึก

โครงการพัฒนาด้วย Node.js และ Express.js สำหรับสร้าง REST API
และใช้ HTML, CSS และ JavaScript สำหรับพัฒนาส่วน Frontend

## โครงสร้างโปรเจกต์

- `server/` เก็บไฟล์ Server และ REST API
- `public/` เก็บไฟล์ Frontend
- `data/` เก็บข้อมูลการออกกำลังกาย
- `server/server.js` ไฟล์หลักของ Server
- `public/index.html` หน้าเว็บ
- `public/style.css` รูปแบบและการออกแบบหน้าเว็บ
- `public/script.js` การทำงานของ Frontend และการเรียก REST API
